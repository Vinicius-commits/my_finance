Funções utilitárias gerais que são usadas em várias partes do aplicativo, 
mas não se encaixam em nenhuma funcionalidade específica.
Devem ser funções puras e reutilizáveis.

Exemplos:
date_formatter.dart, 
currency_formatter.dart, 
validator.dart (para validações genéricas de formulário), 
logger.dart (para um sistema de log customizado).
