# Domain Layer

Esta camada contém as regras de negócio e entidades do domínio financeiro.

## Entities
Classes que representam os objetos de negócio (ex: Conta, Lancamento, Meta).

## Repositories
Interfaces para acesso a dados (ex: IContaRepository, ILancamentoRepository).

## Failures
Classes para representar falhas/erros do domínio (ex: ValidationFailure).
