# Presentation Layer

Esta camada contém a interface do usuário e lógica de apresentação.

## Pages
Páginas/screens da aplicação (ex: DashboardPage).

## Widgets
Componentes reutilizáveis da UI (ex: SaldoCard, TransactionTile).

## Bloc
Gerenciamento de estado usando Cubits (ex: LancamentoCubit, ContaCubit).
