# Infrastructure Layer

Esta camada contém implementações concretas de acesso a dados e serviços externos.

## Repositories
Implementações dos repositórios com Sqflite (ex: ContaRepositoryImpl).

## Datasources
Fontes de dados concretas com Sqflite (ex: SqfliteFinanceDatasource).

## Models
Modelos de dados para Sqflite com fromMap/toMap (ex: ContaModel, LancamentoModel).
